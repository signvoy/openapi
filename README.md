# signvoy/openapi

The published OpenAPI specification for the [Signvoy](https://www.signvoy.com) e-signature API.

- **`openapi.json`** — source of truth for SDK code generation and external tooling.
- Auto-published from the Signvoy core API on every change (do not edit by hand).
- Changes here trigger regeneration of the language SDKs (e.g. [`signvoy-node`](https://github.com/signvoy/signvoy-node)).
